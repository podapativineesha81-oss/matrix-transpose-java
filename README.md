# 🔄 Matrix Transpose Java

## 📌 Project Overview

The **Matrix Transpose Java** is a simple Java-based application that converts the rows of a matrix into columns. It demonstrates matrix manipulation using two-dimensional arrays.

---

## 🚀 Features

- Accepts matrix dimensions from the user
- Accepts matrix elements
- Displays the original matrix
- Calculates the transpose of the matrix
- Displays the transposed matrix
- Supports rectangular matrices

---

## 🛠️ Technologies Used

- **Programming Language:** Java
- **Data Structure:** Two-Dimensional Array
- **Concept:** Matrix Transpose
- **Input Handling:** Scanner
- **Version Control:** Git & GitHub
